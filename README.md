# ระบบบริหารจัดการหอพักอัจฉริยะ (Smart Dormitory Management System)
> เว็บแอปพลิเคชัน UI Prototype สำหรับนำไปใส่ใน Proposal / ข้อเสนอโครงงาน ธีมสีขาว-ฟ้า (White & Blue) สะอาดตา ใช้งานง่าย โค้ดแยกไฟล์เป็นระเบียบตามหลักสถาปัตยกรรม Modular Component

---

## 🚀 วิธีการติดตั้งและรันระบบ (Quick Start)

เปิด Terminal ในโฟลเดอร์นี้ แล้วสั่งงานดังนี้:

```bash
# 1. ติดตั้ง Dependencies (ถ้ายังไม่ได้ติดตั้ง)
npm install

# 2. เริ่มต้นรันเซิร์ฟเวอร์สำหรับพัฒนา (Development Server)
npm run dev

# 3. หรือ Build เป็นไฟล์ Production พร้อมใช้งาน
npm run build
```

หลังจากนั้นเปิดเบราว์เซอร์ไปที่ลิงก์ที่แสดงใน Terminal (เช่น `http://localhost:5173`)

---

## 🎨 การออกแบบและธีม (Design & Theme)
- **ธีมหลัก:** ขาว-ฟ้า (White & Blue Theme) ตามที่กำหนด
- **ฟอนต์:** Prompt (Google Fonts) อ่านง่าย สวยงาม รองรับภาษาไทยและภาษาอังกฤษ
- **การใช้งานง่าย (User-Friendly):** ไม่ซับซ้อน แบ่งสัดส่วนชัดเจน มีปุ่มสลับมุมมองระหว่าง **"มุมมองผู้เช่า (Tenant)"** และ **"ผู้ดูแล/เจ้าของ (Admin/Owner)"** ได้ทันทีในคลิกเดียว เหมาะแก่การแคปภาพหน้าจอ (Screenshots) ไปประกอบเล่ม Proposal หรือเปิด Demo สดให้อาจารย์/คณะกรรมการดู
